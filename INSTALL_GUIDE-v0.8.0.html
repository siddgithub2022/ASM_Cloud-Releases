What You Need — Shopping List

Hardware & software for a private home cloud rated for laymen

5 min to read
▭

Always-on Host

Old laptop, mini-PC, Raspberry Pi 4/5 (2 GB) or NAS that runs Docker. Pi 5 + SSD is silent, ~5 W.

Don’t use your daily laptop — it sleeps
⬢

External HDD / SSD

500 GB – 4 TB USB, ext4 (Linux) or NTFS (Windows). This is your cloud — back it up.

Mounted at /mnt/storage
⬔

Network

Home router. Optional domain cloud.example.com → host public IP. Without it, http://192.168.1.50:3000 at home works.

How It Fits Together — Architecture

Lean Nextcloud: only file sync, no Calendar/Mail bloat

DATA FLOW
Devices
Desktop ~/PersonalCloud (Tauri notify) + Mobile browse-cloud
Server NestJS
Auth JWT + StorageAdapter + Postgres metadata
External Drive
/mnt/storage/asm-cloud-data/{userId}/... + .versions/ + .asm-chunks/
Caddy :443
Let’s Encrypt auto HTTPS • WebSocket /sync push
PROTOCOL (NEW, NOT WEBDAV)
POST/api/files/upload single ≤100 MB
CHUNK/api/files/chunked/init → /chunk/:i → /complete
SYNC/api/sync/changes?since=<cursor> cursor = base64url(ts,id)
WS/sync push “changes available” → clients sync now
SHARE/api/public/share/:token password/expiry, read-only
◇
Lock: Never auto-overwrites. Conflicts become photo (conflicted copy 2026-09-08).jpg + log. ETag + SHA-256 verified.
03

Step A — Prepare the External Drive

The drive is the cloud volume • 5 minutes

Step A

Windows (dev)

1
Plug drive → Format NTFS → note letter F: → create F:\asm-cloud-data
2
In server/.env set STORAGE_ROOT=F:/asm-cloud-data

Linux / Pi / NAS (prod)

sudo mkdir -p /mnt/storage/asm-cloud-data
sudo mkfs.ext4 /dev/sda1          # only if new/empty! wipes!
sudo mount /dev/sda1 /mnt/storage/asm-cloud-data
echo '/dev/sda1 /mnt/storage/asm-cloud-data ext4 defaults,nofail 0 2' | sudo tee -a /etc/fstab
sudo chown -R $USER:$USER /mnt/storage/asm-cloud-data
ls /mnt/storage/asm-cloud-data    # empty = done

Step B — Install the Server

Pick prod (one-command) or dev (Windows)

B1 RecommendedOne-command prod — Docker + Caddy HTTPSProd
git clone https://github.com/YOURNAME/ASM_Cloud.git
cd ASM_Cloud/server
cp .env.example .env
nano .env   # CHANGE: DB_PASSWORD, JWT_*_SECRET (32+ chars), ADMIN_INVITE_TOKEN,
          # STORAGE_ROOT=/mnt/storage/asm-cloud-data, PUBLIC_BASE_URL=https://cloud.example.com
nano Caddyfile   # top line = your domain
cloud.example.com {
  reverse_proxy server:3000
}
docker compose -f docker-compose.yml -f docker-compose.prod.yml up --build -d
docker compose logs -f server   # wait "ASM_Cloud server listening on ...:3000"
✓
Check: curl -X POST http://localhost:3000/api/auth/register ... → {"user":{"id":...}}
B2 DevWindows without Docker
cd F:\ASM_Cloud\server
copy .env.example .env   # set STORAGE_ROOT=F:/ASM_Cloud/data/storage and DB_TYPE=sqlite
npm install
npm run start:dev   # http://localhost:3000/api
!
DB_TYPE=sqlite is dev only. Prod uses Postgres 15.
VERIFY
curl -X POST http://localhost:3000/api/auth/login -H "Content-Type: application/json" -d '{"username":"alice","password":"S3cure!pass"}'
curl -X POST http://localhost:3000/api/files/upload -H "Authorization: Bearer <token>" -F "file=@hello.txt" -F "path=docs/hello.txt"
curl http://localhost:3000/api/files/download?path=docs/hello.txt -H "Authorization: Bearer <token>" -o hello.txt

npx expo run:ios

2. Browse cloud

Root → 📁 docs/ → 📄 shared.txt → Open (on-demand 206 Range) or Keep offline ✓ → Offline tab (plane-readable, FileSystem.documentDirectory).

Enable auto-upload (Wi-Fi only ON) → Photos/Camera → Run now / Enable background (15 min). Android add foregroundServiceType="dataSync".

4. Share to PersonalCloud

From any app → Share → ASM_Cloud → Shared/ (src/lib/share.ts:1, intentFilters bare rebuild).

Admin — Users, Quotas, Storage

First registered user is isAdmin:true

Admin only 
TOKEN=$(curl -s -X POST https://cloud.example.com/api/auth/login -H "Content-Type: application/json" -d '{"username":"alice","password":"S3cure!pass"}' | jq -r .accessToken)
curl https://cloud.example.com/api/admin/users -H "Authorization: Bearer $TOKEN"
curl -X POST https://cloud.example.com/api/admin/users -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"username":"bob","email":"bob@home","password":"Another!pass","quotaBytes":"5368709120"}'
curl -X POST https://cloud.example.com/api/admin/users/<id>/quota -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"quotaBytes":"5368709120"}'
curl https://cloud.example.com/api/admin/dashboard -H "Authorization: Bearer $TOKEN"
# → drive {total,free,used,path}  perUser [{username,quotaBytes,usedBytes,quotaUsedPct,fileCount}]
≡
Desktop AdminPanel desktop/src/components/AdminPanel.tsx:1 shows drive total/free, per-user bar, Edit quota, Create user — admin only, else 403.

Share Links & Security

File + folder, password, expiry — public read-only like Nextcloud

curl -X POST https://cloud.example.com/api/shares -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"path":"docs/report.pdf","password":"s3cret","expiresAt":"2026-12-31T00:00:00Z"}'
# → {"token":"xfqRhYXQjxk_","url":"/api/public/share/xfqRhYXQjxk_"}
curl https://cloud.example.com/api/public/share/xfqRhYXQjxk_                           # info (hasPassword?)
curl https://cloud.example.com/api/public/share/xfqRhYXQjxk_/download -H "X-Share-Password: s3cret" -o report.pdf
# folder
curl -X POST https://cloud.example.com/api/shares -H "Authorization: Bearer $TOKEN" -d '{"path":"Photos","isFolder":true}'
✓
Security: JWT 15m + refresh 7d, argon2, share argon2 + expiry 403, every endpoint checks owner/share, ETag + SHA-256, TLS via Caddy Let’s Encrypt server/Caddyfile:1. Desktop ShareDialog / Mobile Share copy .../api/public/share/.../download.

Go Live — HTTPS via Caddy

Automatic Let’s Encrypt • one domain

1. DNS

Domain cloud.example.com → host public IP (router forward 80,443 → host).

2. Env & Caddyfile

.env PUBLIC_BASE_URL=https://cloud.example.com CORS_ORIGIN=https://cloud.example.com • Caddyfile line 1 = your domain → reverse_proxy server:3000

docker compose -f docker-compose.yml -f docker-compose.prod.yml up --build -d   # Caddy auto-TLS + WebSocket proxy
# home-only: skip Caddy, use http://192.168.1.50:3000
!
Never expose Postgres 5432 publicly — prod binds 127.0.0.1:5432:5432 only.

Cheat-Sheet — All Commands

Copy-paste ready • Phase 1–8

# Server health
docker compose ps
docker compose logs -f server | grep ASM_Cloud
# Auth
curl -X POST http://localhost:3000/api/auth/register -H "Content-Type: application/json" -d '{"username":"alice","email":"alice@home","password":"S3cure!pass","inviteToken":"..."}'
curl -X POST http://localhost:3000/api/auth/login -H "Content-Type: application/json" -d '{"username":"alice","password":"S3cure!pass"}'
# Files
curl -X POST http://localhost:3000/api/files/upload -H "Authorization: Bearer $TOKEN" -F "file=@big.mp4" -F "path=videos/big.mp4"   # chunked auto >10MB
curl http://localhost:3000/api/files/download?path=videos/big.mp4 -H "Authorization: Bearer $TOKEN" --range 0-10485759 -o part.bin
curl "http://localhost:3000/api/sync/changes?since=<cursor>" -H "Authorization: Bearer $TOKEN"
# Shares
curl -X POST http://localhost:3000/api/shares -H "Authorization: Bearer $TOKEN" -d '{"path":"docs/report.pdf","password":"x"}'
curl http://localhost:3000/api/public/share/<token>/download -H "X-Share-Password: x" -o report.pdf
# Admin
curl http://localhost:3000/api/admin/dashboard -H "Authorization: Bearer $TOKEN"
# Clients
cd desktop && npm run dev          # or npm run tauri:dev
cd mobile && npx expo start        # 10.0.2.2:3000 on Android emulator
